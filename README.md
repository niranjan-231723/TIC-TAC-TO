
Tic-Tac-Toe
A simple browser-based Tic-Tac-Toe game built with vanilla HTML, CSS, and JavaScript — no frameworks or libraries required.

Features
1. Classic 3x3 Tic-Tac-Toe gameplay for two players (X and O)
2. Win detection across all 8 possible winning patterns (rows, columns, diagonals)
3. "New Game" button to reset the board and play again
4. "Reset Game" button for a full board reset
5. Simple, clean UI styled with custom CSS


How to Play
1. Two players take turns clicking on the empty boxes.
2. The first player's move is marked O, the second player's move is marked X (turns alternate automatically).
3. The first player to align three of their marks in a row, column, or diagonal wins.
4. A congratulations message appears announcing the winner.
5. Click New Game to reset the board and play again.


Tech Stack
- HTML5 — structure/markup
- CSS3 — styling and layout (Flexbox, CSS Grid)
- JavaScript (ES6) — game logic, event handling, DOM manipulation
